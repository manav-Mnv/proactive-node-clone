## Pages

| Page | Content |
| --- | --- |
| **Home** | Hero ("Transform Your Marketing with Proactiv"), logo marquee, features, tools, pricing, testimonials, FAQ, call to action |
| **Features** | Feature breakdown |
| **Pricing** | Plans |
| **Blog** | Articles |
| **Contact** | Contact form |
| **Login** | Firebase Authentication, with protected routes for signed-in users |

## Tech stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Firebase Authentication

## Getting started

```sh
npm install
npm run dev
```

The Firebase web config lives in `src/lib/firebase.ts`. Swap in your own project's config to use your own sign-in.
